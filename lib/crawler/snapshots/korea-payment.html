    고려대학교는 제공자가 동의한 아래의 내용 외의 다른 목적으로 활용하지 않습니다.

    • - 개인정보 수집·이용 목적 : 홈페이지 가입

    • - 개인정보 보유 및 이용기간 : 회원탈퇴시까지
    • - 개인정보 동의 거부권리 안내 : 신청인은 본 개인정보 수집에 대한 동의를 거부하실 수 있으며, 이 경우 홈페이지 가입이 제한됩니다.

납부방법 및 확인

납부방법

  • 전국  은행창구, ATM, 인터넷뱅킹, 폰뱅킹 등을 이용하여 고지서에 기재된 본인 고유 하나은행 가상계좌번호로 등록금 총계(선택한 기타납입금 포함)를 정확하게 전액 일괄송금
    • 분할송금은 불가하며 필히 사전에 본인 이체한도를 확인
      (ATM 1회 이체한도, 인터넷뱅킹 이체 한도 등)
    • 하나은행 외 타 은행을 통하여 입금 시 타행 송금수수료가 부과될 수 있음
  • 송금인은 학생 본인과 상이하여도 무관하며, 수취인(가상계좌의 예금주)이 “고려대(학생이름)”임을 반드시 확인
  • 전액 장학금을 수혜받아 납부할 등록금이 “0원”인 경우에도 반드시 아래 방법 중 하나를 선택하여 등록
     - 기타납입금을 가상계좌로 입금
     - 하나은행 대학 등록금 납부 메뉴에서 0원 입금
     - 하나은행 방문하여 “0원 등록” 처리 

  • 신용카드 결제는 삼성카드 또는 하나카드로 납부 가능(2022년 2학기부터 시행)

     -  삼성카드 납부 후 학자금 대출 실행은 학자금 대출 담당 소속 대학에 등록 상태 확인하고 대출 진행 필요(이중납부 방지) 
     -  학자금대출 문의: 학부- 학생지원팀, 대학원- 일반대학원생은 일반대학원행정팀, 특수·전문대학원생은 특수·전문대학원행정팀

  • 학부 신(편)입생,  분할납부생, 수료연구생의 학위청구등록금(5월,11월 초 납부)은 신용카드로 등록금 납부가 불가함​​​ 

  • ☆ 등록금은 가상계좌 납부 또는 신용카드 결제 또는 학자금대출 실행 등의 방법 중 1가지 방법으로만 납부

    • 등록금 납부 후 결제방식 변경이 불가하니 신중한 결제 부탁드립니다.

가상계좌: 본교가 각 학생에게 부여한 고유계좌로, 가상계좌로 송금된 입금액이 본교 등록정보와 일치할 경우 해당 학생이 자동 등록 처리됨

가상계좌로 납부방법
  • 하나은행 홈페이지(웹/앱)접속→개인인터넷뱅킹 인증서로그인→공과금→대학등록금→학교선택→학번입력
  • 하나은행 ATM, 폰뱅킹(☎1599-1111) 접속→공과금→대학등록금→학교선택→학번입력

 

신용카드(삼성카드)로 납부방법
  • 삼성카드 홈페이지(웹/앱)접속 →대학등록금→신청하기→인증(앱 카드인증 OR카드인증)→학교선택→학번입력
  • 콜센터(☎1688-9702)
  • 납부가능시간( 등록기간 9:00 ~ 16:00)

 

신용카드(하나카드)로 납부방법
  • 하나은행 홈페이지(PC)접속→개인인터넷뱅킹 인증서로그인→공과금→대학등록금→학교선택→학번입력
  • 전국 하나은행 영업점  방문
  • 하나카드 및 특별한도 신청 (☎1800-1111)
  • 하나은행 어플(앱)에서의 하나카드 결제는 지원하지 않으니 양해해주십시오.(PC이용)

 

 

납부확인

등록상태 : 납부 10분 후에 확인

   포털로그인 →학사 → 등록/장학 → 등록 → 등록금납부내역 조회에서 “등록상태” 확인

등록 내역은 고지금액이며, 실제납입 내역은 아래의 방법에 따라 출력

등록영수증: 납부 10분 후에 확인

   포털로그인 전→ 제증명 →  등록금납부확인서 출력 (발급비용 없음)

   고려대학교 홈페이지→ 교육정보 → 증명서/신분증 → 인터넷증명서신청 →  등록금납부확인서 출력

   (교육비납입증명서는 연말정산 소득공제용 증명서)

 

 

 

유의사항

등록기간 내에 가상계좌입금 및 고지서출력이 가능하므로 해당 기일을 반드시 준수! 

등록금은 납부 완료 후 결제방식 변경을 이유로 환불 불가합니다.

(예시, 카드결제  또는 현금결제 등록 취소 후 학자금대출 결제, 현금결제 등록 취소 후 카드 결제  등→ 불가)

결제방식의 신중한 선택을 부탁드립니다. 


 

  •  "등록금 고지서는 포털 → 학사 →등록/장학 → 등록 → 등록금고지서출력"에서 조회, 외부 링크 조회 불가합니다.

  학부 신입생  (☞ 입학처 바로가기) & 외국인( Foreigners  ☞  oia.korea.ac.kr )  대학원 신입생 (☞고지서(홈페이지) 바로가기)
