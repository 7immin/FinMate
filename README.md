# FinMate

한국에 있는 외국인 유학생을 위한 금융 앱 프로토타입입니다. "목적을 증명하면 한도가 열린다"는 컨셉으로,
학비 납부·해외송금·계좌개설·월세보증금이라는 4가지 실제 지출 상황에서 사용자가 서류(목적)를 증명하면
그만큼 이체 한도가 열리는 흐름을 목업 그대로 구현했습니다.

이 프로젝트는 **프론트엔드 + Mock 데이터** 로만 구성된 프로토타입입니다. OCR 판독, 은행 계좌 연동,
등기부 조회 같은 실제 백엔드 연산은 존재하지 않으며, 실제처럼 보이도록 지연 시간과 결과를 흉내 낸
mock 로직(`lib/mock/*.ts`)으로 대체되어 있습니다.

## 기술 스택

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (다크 테마 디자인 시스템)
- React Context 기반 전역 상태 관리 (`lib/state/AppStateContext.tsx`) — localStorage에 저장되어
  새로고침해도 진행 상태가 유지됩니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 접속 (모바일 너비 화면에 최적화되어 있습니다. 개발자 도구의
기기 툴바로 보는 것을 권장합니다).

## 화면 구성

| 경로 | 설명 |
|---|---|
| `/onboarding` | 언어 선택 → 프로필 입력 (최초 1회) |
| `/passport` | 금융여권 — 등급(S1~S4)과 다음 등급까지 남은 체크리스트, 납부 기록 |
| `/home` | 홈 대시보드 — 현재 한도, 4가지 빠른 실행, AI 질문 입력 |
| `/tuition` | 학비 납부: 고지서 업로드 → AI 판독 → 결과 확인 → 한도 개방 |
| `/remittance` | 해외송금: 정보 입력 → 한도 점검 → (부족 시) 증빙 제출 → 채널 비교 → 전송 추적 |
| `/account` | 계좌 개설: 보유 서류 체크 → 맞춤 안내 → 지점 찾기 → 창구 제시 카드 |
| `/deposit` | 월세·보증금: 계약서 업로드 → 등기 검증 → 위험 경고 → 보증금 보호 체크리스트 |
| `/ai` | FinMate AI — 카드형 답변 (질문 키워드에 따라 등록금/송금 등 맞춤 답변) |
| `/profile`, `/more` | 내 정보, 더보기 (데모 초기화 포함) |

## 데모 진행 순서 (권장)

앱은 최초 접속 시 **금융여권 S1 (한도 300,000원)** 상태에서 시작합니다. 이는 1e 온보딩 플로우가
"새로 입국한 유학생"을 시작점으로 설계되어 있기 때문입니다.

1. `/onboarding`에서 프로필을 입력하면 `/passport`로 이동합니다.
2. `/passport`의 체크리스트 항목을 눌러 확인을 완료하면(S1: 3개 → S2: 2개) 자동으로 등급이
   S2, S3로 올라가며 한도가 늘어납니다. **S3(한도 1,000,000원)** 까지 올리면 목업 화면
   1a~1d에서 보여준 것과 동일한 기준 상태가 됩니다.
3. 이후 홈 화면의 "바로 하기"에서 학비 납부·해외송금·계좌개설·월세보증금 플로우를 자유롭게
   체험할 수 있습니다. 각 플로우를 완료하면 금융여권에도 반영됩니다.
4. `/more`의 "데모 초기화"로 언제든 처음 상태로 되돌릴 수 있습니다.

## 목업과 다르게 구현/보완한 부분

원본 목업(Claude Design)에는 일부 플로우의 뒷부분 단계가 다이어그램상의 라벨로만 존재하고 화면으로는
그려져 있지 않았습니다(해외송금의 "채널 비교→전송→도착 추적", 월세보증금의 "한도 개방+자동납부→일정
등록"). 해당 구간은 앞뒤 맥락에 맞춰 자연스럽게 이어지는 화면을 새로 설계해 채워 넣었습니다.
